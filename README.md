# Тараканья готика

Браузерная 3D-игра в духе старой «Готики». Безымянный Кирилл живёт в двушке, и у него тараканы. За семь дней ему нужно с ними разобраться. Помогут гель, уборка, заделанные щели и разговоры с соседкой Любовью Ивановной и управдомом. Ещё в квартире живут сами тараканы, и с ними тоже можно поговорить: чем крупнее таракан, тем философичнее беседа.

**Играть: https://lstartse-rgb.github.io/tarakany-gothic/**

Нужен компьютер с клавиатурой и мышью, на телефоне игра не работает. Прогресс сохраняется в браузере.
